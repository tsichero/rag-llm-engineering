# RAG & LLM Engineering

> **Portfolio project · AI Engineering · RAG · LLMs · Evaluation**

Projeto técnico de Engenharia de IA focado em **recuperação de contexto, integração com LLMs, avaliação e reprodutibilidade**.

## Objetivo

Demonstrar como estruturar um fluxo de RAG de forma modular, com separação entre recuperação, contexto, geração e avaliação.

## Foco técnico

- recuperação de contexto;
- RAG e integração com LLMs;
- Engenharia de Prompt;
- avaliação de respostas;
- testes automatizados;
- experimentação reproduzível;
- documentação técnica.

## Princípio de engenharia

**retrieval → contexto → geração → avaliação → melhoria**

O objetivo é transformar experimentação com IA em componentes que possam ser testados, versionados e evoluídos.

## Status

**Projeto técnico em evolução.**

As implementações e limitações devem ser consultadas no código e nos artefatos versionados do repositório.
